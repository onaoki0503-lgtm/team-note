## 概要

現在は大学寮Hヴィレッジに絞り、アイデアから企画・日常業務・資料と名簿の引き継ぎまでを検証するReactアプリ。将来のスポーツ団体・PTA・マンション管理組合向けクラウドサービスの設計に、今回の実証を再利用する。

- [最新版の操作デモ（ログイン不要）](https://onaoki0503-lgtm.github.io/team-note/?demo=1)

## 操作と画面

下部ナビはアイデア・進行中・はたらく・保管するの4項目。プロフィールは右上のアバターから開く。
ヘッダーの戻るとブラウザ履歴を連動し、開いた直前の画面へ戻る。入力内容は主要フォームで同じアプリ起動中に保持し、ホーム投稿の下書きは端末にも保存する。

ホームの吹き出しは上限12件で、スマホの1画面に収まる固定領域へ追加する。縦スクロールや時間による交代は行わない。白いガラス調で雲形・楕円・角丸など6種類の輪郭と大きさを変え、重ならない枠内で漂わせる。吹き出しは短いプレビュー、タップすると全文・いいね・削除・企画化を開く。140文字の投稿、最後のいいねから7日間無反応での表示終了、12件超過時に古い順の表示終了、元投稿の保持は継続する。

## 開発

```bash
npm install
npm run dev -- --host 127.0.0.1
npm run build
npm run lint
```

React + TypeScript + Viteを使用。AIは専用Cloudflare Worker、プロフィール／名簿とアイデア・いいねはSupabaseへ接続する。通常入口はメール認証と初回プロフィール登録が必要。操作デモ（?demo=1）は共有DBへ接続せず、既存の端末内保存で操作感を確認できる。企画・報告・備品は引き続き端末内保存。`npm run worker:dev`と`npm run dev`でローカル起動し、`npm run test`で操作を検証する。公開URLの確認は実AI呼び出しを含む`npm run test:public`を使う。実認証／共有DBの複数端末通し確認と実マイクの試験は未完了。

### Flutter（iOS / Android）

利用者向けネイティブ案は `mobile/`（TeamKaikeiとは別プロジェクト）。共有トークンは `shared/design-tokens.json` と `shared/team-note-theme.css`。見た目の共通ルールは [docs/STYLEGUIDE.md](docs/STYLEGUIDE.md)。手順は [mobile/README.md](mobile/README.md)、TestFlightは [mobile/TESTFLIGHT.md](mobile/TESTFLIGHT.md)。
