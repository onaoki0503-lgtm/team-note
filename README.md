## 🌟 プロダクト概要

「チームノート（Team Note）」は、慶應義塾大学 SFC Hヴィレッジをはじめとする自律運営組織・学生寮・自治会・サークル・各種団体に向けた、**「アイデア発起 ➔ 規約・抜け道ハッキング ➔ 企画書出力 ➔ 業務報告 ➔ 組織台帳金庫」**を一気通貫で管理するWebアプリケーションです。

---

## 📱 主要機能（4大ボトムナビゲーション ＆ アプリ共通基盤）

0. 📲 **PWAアプリ化 ＆ H生ログイン・アカウント切替**
   - **PWA（ホーム画面追加）対応**: スマホの「ホーム画面に追加」からネイティブアプリ同様に全画面起動可能。
   - **H生ログイン**: Hヴィレッジ4棟（ローズマリー、バジル、ターメリック、パプリカ）の登録寮生からワンタップ切替、または新規寮生をその場で登録してログイン。
   - **ヘッダー表示**: ログイン中の顔写真・氏名・棟・部屋番号・役職を常時表示。

1. 💡 **イータを変える**
   - 思考を妨げないまっさらな**ホワイトボード（ドットグリッド背景）**。
   - 画面下部からアイデア吹き出しが秒速でポコポコ湧き上がるアニメーション演出。
   - 中央の「アイデア運営をスタート」丸ボタンから、タイトル・本文・写真・議事録をワンタップ挿入。
   - 瞬時に**思考マッピング展開 ＆ 公式企画書（目的・背景・現行ルールの抜け道・具体的アクション・必要予算）**を自動出力。

2. 🚀 **進行中（プロジェクト検索 ＆ スタッフ参加）**
   - **インクリメンタル検索**: プロジェクト名・詳細・担当者・参加スタッフ名・キーワードによるリアルタイム検索。
   - **参加状況・カテゴリ絞り込み**: 「すべて」「自分が参加中」「自分が発起」の切り替え、およびカテゴリタグフィルター。
   - **スタッフ参加（ジョイン）トグル**: 各プロジェクトカードに参加スタッフのアバター列を表示し、「🙋‍♂️ スタッフとして参加する」「✅ スタッフ参加中（離脱）」をワンタップ切り替え。
   - 自分が関わる進行中プロジェクトの進捗度（%）やネクストアクションをリアルタイム管理。

3. 📝 **はたらく**
   - 夜間見回り・ゴミ分別・キッチン清掃・設備点検などの**現場業務報告書**をスマホから即座に作成・提出。
   - 提出履歴とステータス（報告完了 / 要対応）の即時確認。

4. 📦 **倉庫**
   - **4棟・階別ユニット住人台帳**: ローズマリー、バジル、ターメリック、パプリカの各棟・各フロアの住人名簿・役職・連絡先・メモを一目で把握。
   - **過去の公認資料金庫**: ハウス規約、申請書原本、惜敗ログ（過去に却下された理由と突破口の記録）を年度別に一元保管。

## 🗄️ データベース設計（Supabase / PostgreSQL）

本プロダクトは、クラウドデータベース（Supabase）とローカル永続化（LocalStorage）の**ハイブリッドアーキテクチャ**を採用しています。環境変数未設定時でも完全に動作し、Supabase接続キーを設定すれば即座にマルチデバイス共有型クラウドDBへ昇格します。

### テーブル構成（`supabase/schema.sql` 準拠）
| テーブル名 | 説明 |
|:---|:---|
| `organisations` | 組織マスタ（団体名、プラン、説明） |
| `profiles` | ユーザー・寮生プロファイル（氏名、役職、棟、部屋） |
| `residents` | 棟・階別ユニット住人台帳（現場名簿） |
| `projects` | 進行中プロジェクト（進捗率、担当者、次回アクション） |
| `project_nodes` | 思考マッピングノード（課題、規約突破法、写真等） |
| `work_reports` | 業務報告書（見回り、点検、清掃ログ） |
| `team_assets` | 倉庫資料・公認規約・過去惜敗ログ |
| `team_asset_files` | 添付ファイル・各種書類URL |
| `team_order_meta` | ラクスル型受発注メタデータ（印刷物・備品発注履歴） |

- **初期データ投入用SQL**: `supabase/seed.sql`

## 🚀 開発 ＆ ローカル実行手順

```bash
# 依存パッケージのインストール
npm install

# ローカル開発サーバーの起動
npm run dev

# 本番ビルド（TypeScript型チェック ＆ Viteビルド）
npm run build
```

### Supabaseの接続設定（任意）
`.env` ファイルを作成し、以下を設定してください：
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```
