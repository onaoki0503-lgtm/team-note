## 実行

アプリ直下で`npm run test`（吹き出し管理・Worker・ブラウザを順に実行）。吹き出し管理だけは`npm run test:ideas`。Node.js 22.14以降とChromeが必要。macOS標準のChromeパス以外を使う場合は`CHROME_PATH`を指定する。

Workerの契約・失敗・入力制限・Origin・レート制限をNodeのテストで確認し、実Chrome＋workerdで画面遷移・投稿・報告・AI経路・保存失敗・4画面幅・減動を操作する。

ブラウザ試験はlocalhost:5174、テストWorkerはlocalhost:8788。通常の確認用localhost:5173・Worker:8787と分ける。新規ブラウザの端末データだけを変更し、外部HTTPS通信は遮断する。Workers AIだけを試験用応答へ置き換え、実モデル精度やクラウド権限の確認とは扱わない。

テスト結果・失敗時のスクリーンショットは`/private/tmp/teamnote-glass-*`へ出力し、同期フォルダに大量生成しない。
